## 1. Teaching arc

Build a progressive story rather than disconnected cards. A reliable sequence is:

1. definition;
2. familiar comparison;
3. capability or mechanism;
4. why it matters;
5. concrete tool or scenario;
6. limitation and human role;
7. takeaway.

The cover should create curiosity instead of summarizing every page.

## 2. Cognitive-anchor page selection

Do not split the source evenly or create one page per paragraph. First list candidate moments, then keep only the moments that materially change the reader's mental model.

Strong cognitive anchors include:

- a core judgment the reader should remember;
- a cognitive turn that replaces an intuitive but wrong model;
- a meaningful comparison;
- an input/output break, bottleneck, or feedback loop;
- a boundary, limitation, or human-control point;
- a common mistake with a visible consequence;
- a character or system state change;
- a final relationship that compresses the whole topic.

For each candidate, write one sentence answering: “If this page disappears, what understanding is lost?” Drop candidates with no concrete answer. Merge adjacent anchors that teach the same relationship. Default to 5–8 inner pages, but stop when the arc is complete.

## 3. Page archetypes

### Cover

Use a large topic title, a short question or promise, the host character, and one iconic object. Keep it text-light and readable as a thumbnail.

### Definition

Give one plain-language definition, one familiar comparison, and one short takeaway.

### Comparison

Give both sides equal visual weight. State the meaningful difference rather than claiming one side is universally better.

### Capability grid

Use four or fewer cards. Give each card one verb, one icon, and one short explanation.

### Mechanism or process

Use 4–6 steps. Show input, action, feedback, and completion. Make every arrow connect an unambiguous source and destination.

### Before and after

Use a small narrative. Avoid implying full autonomy where human approval remains necessary.

### Tool example

Explain a named product through a verified user goal and short workflow. Do not use a logo as the whole page.

### Human control and boundary

Show that humans set goals, grant permissions, review results, and adjust direction.

### Summary

Use one memorable sentence and one simple relationship diagram. Do not repeat every previous bullet.

## 4. Copy limits

- Cover title: prefer 6–16 Chinese characters, with an optional short subtitle.
- Page title: prefer 5–14 Chinese characters.
- Anchor sentence: usually 12–32 Chinese characters.
- Supporting labels: 3–5 items, usually no more than 12 characters each.
- Avoid paragraphs, repeated conclusions, and unexplained jargon inside images.
- Use conversational contrasts only when they improve understanding.

## 5. Storyboard contract

For every page specify:

- page number and archetype;
- cognitive-anchor type and why it deserves a page;
- exact title and one key message;
- abstract concept, physical action, and ordinary object;
- resolved visual metaphor;
- the character's indispensable core action;
- character pose and expression;
- supporting objects;
- arrows or reading flow;
- exact text blocks;
- evidence or source notes;
- continuity requirements.

## 6. Post copy

Write `post.md` with:

- 2–3 candidate titles, then identify the recommended title;
- a strong opening sentence;
- concise paragraphs that add context beyond the images;
- a final takeaway or discussion prompt;
- source notes when required;
- 3–8 relevant hashtags without keyword stuffing.
