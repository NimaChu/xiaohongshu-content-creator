# Original Visual Metaphors

Use this method for every selected cover or inner page. Invent from the current topic; do not recycle a memorable scene merely because it worked before.

## Three-step method

1. **Abstract concept → physical action.** Translate the idea into something that can happen in space: filter, squeeze, carry, sort, connect, block, leak, weigh, fold, unlock, recycle, or hand over.
2. **Physical action → ordinary object.** Choose one low-tech object that naturally performs or resists that action: funnel, drawer, pipe, scale, door, ladder, mailbox, sieve, spool, toolbox, bridge, stamp, or workbench.
3. **Character performs the action.** Make the selected IP push, pull, catch, sort, repair, weigh, connect, guard, or operate the object. The action must express the key message.

Use one primary object and at most two supporting objects. Prefer a slightly strange but immediately legible scene over a formal diagram.

## Character-dependency test

Mentally remove the character:

- If the core relationship still reads exactly the same, the character is decorative. Rewrite the scene so its action causes, blocks, repairs, or reveals the result.
- If removing the character breaks the metaphor's meaning, the role is strong enough.

Do not make the character point at a finished diagram when it could instead operate the diagram as a physical system.

## Originality test

Before generation, compare the scene with earlier pages in the same series:

- change the primary object when two pages use the same mechanism;
- change both object and action when the silhouette feels repeated;
- keep the conceptual relationship, not a borrowed composition;
- avoid a dense collection of arrows, cards, and labels that turns the metaphor into a PPT diagram.

## Prompt contract

State these separately:

- `cognitive_anchor`: what understanding this page changes and why it merits a page;
- `metaphor.concept`: the abstract idea;
- `metaphor.physical_action`: the physical verb;
- `metaphor.everyday_object`: the ordinary low-tech object;
- `character_action`: the indispensable action performed by the IP;
- `visual`: the final scene and composition;
- `character_pose`: expression, viewing angle, and body pose only.
